# Linienbegleiter (Лайниенбеляйтер) 🚍

[![Android](https://img.shields.io/badge/Platform-Android-3DDC84?style=flat&logo=android&logoColor=white)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.0+-7F52FF?style=flat&logo=kotlin&logoColor=white)](https://kotlinlang.org)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack_Compose-Material_3-4285F4?style=flat&logo=jetpackcompose&logoColor=white)](https://developer.android.com/compose)
[![MapLibre](https://img.shields.io/badge/MapLibre-GL_Native-4285F4?style=flat)](https://maplibre.org)

**Linienbegleiter** — это современное Android-приложение для водителей общественного транспорта, пассажиров и энтузиастов транспортной навигации. Приложение создано на базе **Jetpack Compose** и **MapLibre GL**, сочетая в себе высокую производительность, плавную навигацию и эргономичный игровой HUD-интерфейс.

---

## ✨ Ключевые особенности и возможности

### 1. 🗺 Плавное GPS-следование без мерцания
* Полностью устранено мерцание названий улиц и иконок на карте за счёт разделения потоков рендеринга статических линий маршрута и динамической геопозиции.
* Плавная покадровая интерполяция перемещения маркера между GPS-точками.
* Сохранение последнего известного положения при кратковременной потере сигнала GPS.

### 2. 🎮 Тактический HUD-интерфейс (в стиле PUBG)
* Максимально открытая карта: убраны все массивные блоки и баннеры.
* Компактная плавающая «пилюля» с названием маршрута в левом верхнем углу.
* Управление симуляцией через компактные кнопки (зелёный старт `▶` / красный стоп `⏹`) в правом верхнем углу.
* Ультракомпактная нижняя тактическая панель с неоновой подсветкой, отображающая следующую остановку и дистанцию.

### 3. 📐 3D-перспектива и динамический автомасштаб
* **Переключение 3D / 2D**: Кнопка быстрого переключения между плоским видом сверху (0°) и объемным навигационным видом (45°) прямо на карте.
* **Автомасштаб по скорости**: В режиме следования масштаб карты автоматически и плавно подстраивается под вашу скорость:
  - Остановка / ползком (< 10 км/ч) $\rightarrow$ масштаб **17.5**.
  - Городской поток (10–30 км/ч) $\rightarrow$ масштаб **16.5**.
  - Средняя скорость (30–60 км/ч) $\rightarrow$ масштаб **15.5**.
  - Трасса (> 60 км/ч) $\rightarrow$ масштаб **14.5** (широкий обзор вперед).

### 4. ⚠️ Детектор схода с маршрута
* Автоматический контроль отклонения автобуса от записанной линии трека.
* Настраиваемый порог отклонения в настройках приложения (от 10 м до 100 м с шагом 5 м, по умолчанию — 25 м).
* Защита от ложных срабатываний (гистерезис по нескольким последовательным точкам) и мгновенный красный предупреждающий баннер при сходе с линии.

### 5. ⚙️ Полная кастомизация интерфейса в настройках
* В меню настроек можно в один клик включать или отключать любые элементы управления на карте:
  - Кнопки зума (`+` / `−`)
  - Кнопку переключения 3D / 2D
  - Компас (ориентацию на север)
  - Индикатор текущей скорости

### 6. 🔴 Запись, редактирование и импорт маршрутов
* Запись треков и остановок в реальном времени.
* Редактор маршрутов с поддержкой секций и направлений.
* Импорт и экспорт данных.

---

## 🛠 Технологический стек

* **UI:** Jetpack Compose, Material 3, Custom HUD overlays.
* **Карты:** MapLibre GL Native Android SDK.
* **Архитектура:** MVVM, Kotlin Coroutines & Flow.
* **База данных:** Room (SQLite) для локального хранения маршрутов, остановок и сессий.

## 📦 Установка и сборка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/zuLiebe/Linienbegleiter.git
   ```
2. Откройте проект в **Android Studio**.
3. Соберите и запустите приложение на устройстве или эмуляторе:
   ```bash
   ./gradlew assembleDebug
   ```
