# Getting Support for Linienbegleiter

Thank you for using **Linienbegleiter**! Here is how you can get help or report issues.

---

## 1. Documentation
Before asking for help, check the official project documentation in `docs/`:
- [BUILD.md](docs/BUILD.md) — How to build and run the app.
- [FEATURES.md](docs/FEATURES.md) — Overview of features and capabilities.
- [DATA_FORMATS.md](docs/DATA_FORMATS.md) — Information on GPX, GeoJSON, and GTFS formats.
- [DEVELOPMENT.md](docs/DEVELOPMENT.md) — Guidelines for developers.
- [TESTING.md](docs/TESTING.md) — Unit testing and verification commands.

---

## 2. GitHub Issues
If you encounter a bug or have a feature request:
- Search existing [GitHub Issues](https://github.com/) to see if it has already been reported.
- Create a new issue using our templates:
  - **Bug Report:** For errors, crashes, or unexpected behavior.
  - **Feature Request:** For proposing new ideas or improvements.

---

## 3. Community Discussions
For general questions, usage discussions, or sharing custom transit routes and formats, please use the project's GitHub Discussions forum.
